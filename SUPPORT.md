# Support / 用户支持

## Public GitHub issues

Use a public GitHub issue only for a reproducible NoveMD software defect or a problem with a file published in this repository.

公开 GitHub Issue 仅用于可复现的软件问题，或本仓库公开下载文件本身的问题。

Before reporting, please include the NoveMD version, Windows version, steps to reproduce, expected result and actual result. For an import or export problem, identify the source/target format and the application used to open the result.

提交前请注明 NoveMD 版本、Windows 版本、复现步骤、预期结果和实际结果。导入或导出问题还应注明文件格式，以及打开导出文件的软件。
