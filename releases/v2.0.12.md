Release date: 12 September 2026<br>
Platform: Windows 10/11, 64-bit

> After the 30-day full-featured trial, ordinary Markdown—including AI-generated `.md` files—can still be opened, read and exported. Only editing requires a perpetual licence. One-time pricing is **¥49 CNY** in Mainland China and **US$9.90 USD** internationally, with no subscription or automatic renewal.

## 本版重点 / Highlights

- 统一复杂 Markdown/README 图片组、声明尺寸、对齐方式和显式换行的解析，修复首次打开不完整、图片撑屏、错位及同组图片大小跳变。
- 改进远程图片缓存、渐进加载和跨文档刷新隔离，减少慢图片或瞬时失败造成的旧图串入。
- 保留 GitHub 主题图片、相对图片和图片超链接的原始语义，继续兼容普通 HTML、无样式 HTML、PDF、Word、PowerPoint、TeX 与离线阅读包导出。
- Added consistent image-group layout, declared sizing, alignment and explicit-break handling for complex Markdown/README files, fixing incomplete first opens, oversized media, misalignment and size jumps.
- Improved remote-image caching, progressive loading and cross-document refresh isolation so slow or transient failures cannot leak stale images into the current document.
- Preserved GitHub-themed, relative and image hyperlinks across the existing HTML, PDF, Word, PowerPoint, TeX and offline-package export paths.

## 中文说明

2.0.12 面向复杂 README 和多格式交付场景，重点修复图片在首次加载、切换文档、窄屏显示和导出时的通用布局问题。远程图片优先复用安全缓存并按完成顺序渐进呈现，图片组仍遵循源文档的顺序、声明尺寸、对齐和显式换行。图片超链接与文字链接继续保留目标地址。

## English release notes

2.0.12 focuses on generic image fidelity for complex README files and multi-format delivery. Remote images reuse validated cache entries and appear progressively in completion order; image groups preserve source order, declared dimensions, alignment and explicit breaks. Text and image hyperlink destinations remain available throughout the supported export paths.
